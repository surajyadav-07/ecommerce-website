# 🛒 Amazon Clone (UI Design)

A frontend UI clone of the popular e-commerce platform, Amazon. This project focuses on replicating the look, layout, and styling of the original website using pure HTML and CSS.

🔴 **Live Demo:** ecommerce-website-three-umber.vercel.app
---

## ✨ Features

*   **Accurate UI Replica:** Detailed header, navigation bar, and footer designed to look exactly like the real Amazon website.
*   **Product Layout:** Clean and organized product cards using CSS Flexbox/Grid to display images, prices, and ratings.
*   **Hover Effects:** Interactive CSS hover animations on links, buttons, and product containers.
*   **Responsive Styling:** Adaptable layout for different screen sizes.

---

## 🛠️ Tech Stack

*   **HTML5:** For creating the semantic structure of the web pages.
*   **CSS3:** For styling, layout structuring, colors, and typography.
